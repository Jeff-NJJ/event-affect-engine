# 通用接入说明（脱敏分享版）

此分享包不含真实服务器地址、SSH 账号、鉴权值、角色路由、数据库、普通记忆正文、设备指纹、个人工作流、原始现场记录或备份位置。`server.example.invalid` 等仅为占位符。

1. 在自己的环境运行情绪服务与 OB 桥。核心使用 Python 标准库；MCP 桥依赖 deploy/requirements-ob.txt。环境参数参考 deploy/environment.example，分别配置自己的 URL 和密钥。不要使用原设备或服务器私有配置。
2. 手机使用不含连接配置的 TOOLPKG。单独设置本地 API 地址、鉴权及真实 chat/card/agent/actor 路由，并核验持久聊天的角色卡和角色组。已有同 ID 旧包应按宿主支持的升级方式处理。
3. 消息接收返回202代表可靠入库；等待 receipt 的 applied/rejected 状态。后台语义分类与当前轮提示独立，不能把尚未完成分类的状态当作最终结论。
4. OB 检索使用完整段落的云向量，缓存按模型、实际维度和全文指纹隔离。派生归档与普通记忆分开，不用系统自己的旧推断给自己作证。
5. 反思/审查默认8192输出token、单次120秒，总期限150秒；带审查修订的生成总期限300秒。代理和客户端总期限应留余量，例如反代330秒。截断输出仍拒绝。
6. 提醒使用 endocrine_native_v2:schedule_one_time_task，重试保留同一request_id；原子领取之后中断应先对账，不盲目重发。离线同步维护任务只重试消息，不唤醒AI。
7. 部署前在自己的环境做一致数据库备份与记忆快照。先备份再切换，恢复旧服务时保留新事件；未经差异核对不要用旧库覆盖当前库。

原始版本已完成工程验收；分享副本不能直接用来连接原部署。独立服务端生成需要明确设置 authored persona，手机身份仍来自已有角色卡。原 APK 通用终端问题和其他供应商的重试逻辑不由本 ToolPkg 修改。
