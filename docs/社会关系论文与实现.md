# 社会关系论文与实现（2026-10-18）

从第一性原理，仿真对象应有明确的主体、目标、知识时间和行动边界：事件原文是观察，语义候选是解释，情绪是相对于目标的评估，关系是带来源的长期认识，发送是独立动作。不能把词语直接换算为激素，也不能把模型的高 certainty 当作事实证明。

## 语义检索的选择

曾用 [Sentence-BERT 原始论文](https://aclanthology.org/D19-1410/) 的表征检索思路试验本地中文向量模型。它能找语义相近段落，但相似度不能保证否定、人物和因果方向正确。按照用户指定的云端架构，本版已移除该运行依赖；不打包或自动下载本地权重。

实际实现使用云端模型读取完整查询与范围内的完整记忆；模型排名必须带原文证据。人物/会话是范围过滤，不是关键词。不能仅仅把字符串包含改成向量近邻就声称“理解了所有含义”。本版也不声称云端模型理解无误；7 个合成检索案例通过仅证明这些案例通过。

## 明示的工程假设

最大事件增益 .30、证据系数 .15、先验质量 3、回应学习率 .10、亲近学习率 .03、半衰期及疲劳系数均待数据校准。closeness、satisfaction 初值 .5 是配置中点，不是测量结果。既有 hormone 字段只是兼容显示，不参与核心反馈。

现在仍有需要验证的问题：模型对复杂指代和混合段落会作出高置信度错误；范围过大的全文检索延迟/费用会上升；用户对角色回应的主观感受无法由角色自证；缺少人类标注的纵向数据和独立测量，无法声称已经复现真实情绪。下一步应使用匿名、经授权的标注集比较人物归属、否定、修复、混合事实和长期轨迹，再调整参数，不能以通过单元测试替代心理学验证。

## 面向类人一致性的本轮迭代

目标是改善理解、连续记忆、边界与不确定性处理，而非给对话增加更多情绪词。当前增加了：独立语义审查；语义找回较早前情且禁止未来记录泄漏；请求/意图与已发生行为分离；边界原文记录；同一观察不因多个解释重复计分。它们是可审计的工程实现，不是研究已经证实的“人类心智复制”。

审查仍用同一云端模型的不同提示，错误可能相关；需要独立标注集与长期真实交互验证。expressed_boundaries 只是所表达偏好的证据，不授予发送、公开信息或其他行动权限；行为执行端仍需正确接入。
